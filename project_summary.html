🧠 Analytics 模組說明
模組 主要方法 輸出 備註
PECalculator calculate(symbol, price) P/E ratio (float) EPS TTM from fundamental_data.json
save / load / get_history pe_history.json 同日覆蓋、按日期排序
MomentumScorer score(bars) 0.0 ~ 1.0 1D×0.20 + 5D×0.35 + 20D×0.45 → sigmoid
score_detail(bars) dict with all fields 不足天數自動重分配權重
Predictor predict(bars) direction + confidence ⚠️ disclaimer 永遠存在
"up" / "down" / "neutral" confidence < 0.45 → 強制 neutral
Top10Analyzer get_top10_snapshot(strategy_id) List[dict] ≤ 10 按市值排序，整合 PE + 動量 + 預測
